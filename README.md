# Stopododo — site officiel

Site statique public de présentation et de conformité de l’application Android **Stopododo**.

## Pages
- Accueil : `index.html`
- Politique de confidentialité : `confidentialite.html`
- Usage du service d’accessibilité : `accessibilite.html`
- Conditions d’utilisation : `conditions.html`
- Contact : `contact.html`

## Publication GitHub Pages
Ouvrir **Settings > Pages**, choisir **Deploy from a branch**, sélectionner `main` et `/(root)`, puis enregistrer.
